# Marina Bay - Golden Hour
This project is a tribute to the ALMIGHTY MARINA BAYYY. Where every evening the skyline catches the light and reflects it in the most beautiful way ever.

## What's here

1. **[BayGuessr](./MarinaBay%20Guesser/)** — a GeoGuesser-style game. You're shown a real photo from around the bay and have to pin exactly where it was taken.
2. **[Trivia](./trivia/)** — a quick quiz on how well you actually know Marina Bay.
3. **[Explore the Bay](./marinabay/)** — a guided look around the bay's landmarks and a small section to know more about it!
